## 🔧 Current Projects
**AllWomen RideShare** is a native Android application built with Kotlin that reimagines rideshare transportation with a safety-first approach designed exclusively for women. The app creates a trusted ecosystem where verified female riders connect with verified women drivers, addressing the critical safety concerns that many women face when using traditional rideshare platforms. Built using modern Android development practices including Material Design 3, MVVM architecture, and the Navigation Component, the application features comprehensive safety mechanisms such as an emergency panic button, real-time location sharing with trusted contacts, and a robust verification system. The platform integrates Google Maps SDK for precise location tracking and route optimization, Firebase for authentication and real-time data synchronization, and implements a sophisticated rating system that evaluates drivers across multiple categories including safety, cleanliness, communication, and punctuality.

The technical architecture demonstrates proficiency in professional Android development, featuring a clean separation of concerns with distinct data, domain, and presentation layers. The app leverages Kotlin coroutines for asynchronous operations, LiveData and ViewModel for reactive UI updates, and Room database for local data persistence. Key features include multiple ride types (Standard, Premium, Shared, and Scheduled), secure payment integration with Stripe and PayPal, in-app emergency contacts management, and comprehensive ride history tracking. The project showcases expertise in handling complex Android permissions, implementing real-time location services, managing network communications with RESTful APIs, and creating an intuitive user experience that prioritizes both functionality and safety. Currently in active development, the app represents a full-stack mobile development effort that addresses a real-world social problem through thoughtful engineering and user-centered design.
